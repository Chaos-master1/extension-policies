Workflow SOP & Guide Recorder — Privacy Policy

Last updated 2026-10-10

What this extension does

Single-purpose workflow SOP recorder that captures clicks, inputs and navigations on https://example.com/*, annotates viewport snapshots with red numbered badges, and generates an editable Markdown + HTML guide locally in the Chrome Side Panel.

Data it handles

This extension does not collect, store or transmit any personal data.

Where that data goes

Nothing is stored or transmitted.

Permissions

  • activeTab — activeTab: Needed to inject the recorder panel container (.wgr-panel) and red numbered badges (.wgr-badge) into the active tab and to capture clicks, inputs and navigations for the step list.
  • hostPermissions — host access https://example.com/*: Content script runs only on https://example.com/* to inject the panel, overlay badges, and record workflow steps where the extension is designed to operate.
  • sidePanel — sidePanel: Needed to display the recorder UI, step list (.wgr-step), filter bar, search (#wgr-search), counter badge and Markdown/HTML export controls in the Chrome Side Panel and to open the panel on action click.
  • storage — storage: Needed to save recorded steps, counters and generated Markdown/HTML locally on-device so the guide persists between sessions without any cloud sync.

Selling and unrelated use

This extension does not sell data to third parties, does not use or transfer data for purposes unrelated to the single purpose stated above, and does not use or transfer data to determine creditworthiness or for lending purposes.
