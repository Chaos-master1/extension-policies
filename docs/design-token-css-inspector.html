Design Token & Computed CSS Inspector — Privacy Policy

Last updated 2026-10-10

What this extension does

Displays an isolated Shadow DOM HUD that maps computed CSS properties to Tailwind classes or CSS variables and provides a side panel for inspection.

Data it handles

This extension does not collect, store or transmit any personal data.

Where that data goes

Nothing is stored or transmitted.

Permissions

  • activeTab — Enables the content script to inject the HUD into specific web pages when triggered by user interaction.
  • storage — Stores local state such as the last selected highlight color and UI preferences without sending data to external servers.
  • sidePanel — Allows the extension to open a dedicated side panel for detailed token inspection when requested by the user.

Selling and unrelated use

This extension does not sell data to third parties, does not use or transfer data for purposes unrelated to the single purpose stated above, and does not use or transfer data to determine creditworthiness or for lending purposes.
