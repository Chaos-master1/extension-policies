Structured Data Extractor for Research — Privacy Policy

Last updated 2026-10-10

What this extension does

Detects HTML tables and embedded JSON/CSV blocks on the current page and converts the selected block to editable markdown in a side panel for export as Markdown, CSV, or JSON.

Data it handles

This extension does not collect, store or transmit any personal data.

Where that data goes

Nothing is stored or transmitted.

Permissions

  • activeTab — activeTab: Reads the DOM of the active tab only when you click an Extract button to parse the selected table or JSON block and convert it to markdown.
  • host_permissions — host access (https://example.com/** via content_scripts): Injects the content script to detect tables and JSON blocks and display inline extract markers. No access to other sites.
  • sidePanel — sidePanel: Displays the editable markdown preview and export bar in the browser side panel and opens the panel when you click the extension action or an extract button.
  • storage — storage: Persists edited markdown and last-used export preferences locally on device so they remain when the side panel is reopened.

Selling and unrelated use

This extension does not sell data to third parties, does not use or transfer data for purposes unrelated to the single purpose stated above, and does not use or transfer data to determine creditworthiness or for lending purposes.
