Mock API & Network Latency Simulator — Privacy Policy

Last updated 2026-10-10

What this extension does

This extension provides a client-side laboratory for mocking API endpoints, simulating network latency, and injecting HTTP status codes.

Data it handles

This extension does not collect, store or transmit any personal data.

Where that data goes

Nothing is stored or transmitted.

Permissions

  • storage — Used to remember user settings and mock rules.
  • activeTab — Allows the extension to interact with the currently active tab for injecting mock rules.
  • sidePanel — Enables the extension to open a side panel for managing mock rules and settings.

Selling and unrelated use

This extension does not sell data to third parties, does not use or transfer data for purposes unrelated to the single purpose stated above, and does not use or transfer data to determine creditworthiness or for lending purposes.
